# Multi-Source Flight Navigator API
🚀 **Live Demo:** [View Live App](https://flight-navigator-api.onrender.com/)
[![FastAPI](https://img.shields.io/badge/FastAPI-005571?style=for-the-badge&logo=fastapi)](https://fastapi.tiangolo.com)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

A high-performance FastAPI web server that aggregates, compares, and sorts flight deals from multiple search engines, namely **Aviasales (Travelpayouts)** and **Google Flights (via SerpApi)**. It executes search queries concurrently using async threading and returns unified, sorted JSON results.

---

## 🌟 Features

* **⚡ Concurrency & Parallel Execution**: Leverages Python's `asyncio.to_thread` to query multiple external APIs concurrently without blocking the main event loop.
* **🌐 Multi-Source Aggregation**: Integrates:
  * **Aviasales (Travelpayouts Month Matrix API)**: Offers a monthly overview of cheap cached flight deals.
  * **Google Flights (via SerpApi Engine)**: Fetches real-time flight data, airlines, flight legs, stops, and pricing.
* **🧠 Intelligent NLP Input Parser**:
  * **Auto IATA Resolution**: Converts city names in English and Russian (e.g., `"Helsinki"`, `"Хельсинки"`) directly to IATA codes (e.g., `HEL`). Direct IATA inputs (e.g., `BCN`, `MUC`) are supported.
  * **Flexible Date Formats**: Recognizes specific dates (`YYYY-MM-DD`, `DD.MM.YYYY`) and general month queries (e.g., `"September"`, `"на сентябрь"`).
* **💰 Price-Sorted Results**: Automatically consolidates flight options from all providers, sorts them by price ascending, and limits the output according to the search mode (`fast` returns top 5, `deep` returns top 15).
* **🔌 CORS Middleware**: Ready-configured CORSMiddleware to allow safe requests from frontend applications (web, mobile, desktop) anywhere.
* **📖 OpenAPI / Swagger Documentation**: Autogenerated interactive documentation page out-of-the-box.

## 🛠️ Tech Stack

* **Core Framework**: [FastAPI](https://fastapi.tiangolo.com/) (Web framework) & [Uvicorn](https://www.uvicorn.org/) (ASGI Server)
* **Language & Runtime**: Python 3.10+
* **Concurrency**: `asyncio` & `threading` (non-blocking thread execution for synchronous HTTP requests)
* **Validation & Networking**: [Pydantic](https://docs.pydantic.dev/) & [requests](https://requests.readthedocs.io/)
* **Configuration**: `python-dotenv` for reading `.env` credentials

## 🚀 Setup & Installation Guide

### 1. Clone the repository
```bash
git clone https://github.com/your-username/flight-navigator-api.git
cd flight-navigator-api
```

### 2. Configure Virtual Environment (Optional but recommended)
```bash
python -m venv venv
# On Windows
venv\Scripts\activate
# On macOS/Linux
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Setup Environment Variables
Create a `.env` file in the root directory by copying the sample template:
```bash
cp .env.example .env
```
Open `.env` and fill in your API tokens:
```env
TRAVELPAYOUTS_TOKEN=your_travelpayouts_token_here
SERPAPI_KEY=your_serpapi_key_here
```

### 5. Run the Server
Launch the FastAPI server with hot-reload enabled:
```bash
uvicorn main:app --reload
```
Once started, the server will run on **`http://127.0.0.1:8000`**.

* **Swagger UI Documentation**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
* **Alternative Redoc Documentation**: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

## 📡 API Documentation & Endpoints

### GET `/api/search`

Finds and returns cheap flights from Aviasales and Google Flights, sorted by price.

#### Query Parameters

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :---: | :---: | :--- |
| `origin` | `str` | Yes | - | Name or IATA code of origin city (e.g. `Helsinki`, `HEL`). |
| `destination` | `str` | Yes | - | Name or IATA code of destination city (e.g. `Barcelona`, `BCN`). |
| `date` | `str` | Yes | - | Date expression (e.g. `2026-09-01`, `September`, `15.09.2026`). |
| `mode` | `str` | No | `deep` | Search depth mode: `fast` (top 5 results) or `deep` (top 15 results). |

#### Request Example (cURL)
```bash
curl -G "http://127.0.0.1:8000/api/search" \
    --data-urlencode "origin=HEL" \
    --data-urlencode "destination=BCN" \
    --data-urlencode "date=2026-09-01" \
    --data-urlencode "mode=fast"
```
